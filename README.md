# Foco nos Estudos

Página web para organizar tarefas de estudo e acompanhar o progresso. As tarefas são salvas no próprio navegador com `localStorage`.

**Demonstração online:** https://bapdaniel.github.io/foco-estudos-web/

## O que pratiquei

- HTML semântico
- CSS responsivo
- JavaScript e manipulação do DOM
- eventos e validação de formulários
- armazenamento local no navegador
- testes de lógica com o test runner nativo do Node.js

## English summary

Responsive study-task organizer built with semantic HTML, CSS, JavaScript modules and localStorage, with automated logic tests.

## Como usar

Abra o arquivo `index.html` em um navegador. Não é necessário instalar dependências.

## Como testar

```bash
node --test
```
